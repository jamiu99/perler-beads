# 拼豆图生成器 - 简化版

## 📁 文件说明

这是一个**简洁实现**的拼豆图生成器，包含所有核心功能。

- `index.html` - 完整的拼豆图生成器（HTML + JavaScript）
- `color-palette.json` - 可配置的色板数据文件（288种颜色，支持5个品牌色号体系）

## 🚀 使用方法

### 方式1: 直接打开

```bash
# 在浏览器中打开
open index.html

# 或者
# Windows: 双击 index.html
# Mac: 右键 -> 打开方式 -> 浏览器
```

## ✨ 功能清单

### 1. 图片上传和预览
- ✅ 支持点击上传
- ✅ 支持拖放上传
- ✅ 支持 JPG、PNG 格式
- ✅ 实时显示原图预览和尺寸

### 2. 图片转化参数

#### 2.1 像素化粒度
- **功能**: 控制横向格子数量（10-150）
- **说明**:
  - 数值越大 = 格子越多 = 图片越精细 = 需要更多拼豆
  - 数值越小 = 格子越少 = 图片越粗糙 = 需要更少拼豆
- **推荐值**:
  - 简单图案: 20-30
  - 中等复杂: 40-60
  - 精细作品: 80-120

#### 2.2 双模式选择

**主导色模式（Dominant）**
- **原理**: 取区域内出现最多的颜色
- **适用场景**:
  - ✅ 卡通动漫角色（如皮卡丘、马里奥）
  - ✅ Logo 和品牌标识
  - ✅ 对比清晰的图案
- **特点**: 色块纯净、边界清晰

**平均色模式（Average）**
- **原理**: 计算区域内所有颜色的平均值
- **适用场景**:
  - ✅ 真实照片（人物肖像、风景）
  - ✅ 需要颜色渐变的图案
- **特点**: 颜色过渡自然、细节丰富

#### 2.3 色号体系（品牌）
- **选项**: MARD、COCO、漫漫、盼盼、咪小窝
- **说明**: 不同品牌对同一颜色的编号不同，选择你购买拼豆的品牌
- **示例**:
  ```
  白色在不同品牌:
  MARD: H1
  COCO: H01
  漫漫: H1
  盼盼: 1
  咪小窝: 1
  ```

#### 2.4 颜色映射计算
- **使用**: color-diff 库
- **算法**: CIEDE2000 感知色差
- **优势**: 比简单的 RGB 距离更符合人眼感知

### 3. 拼豆图预览
- ✅ 实时显示转换结果
- ✅ 显示网格尺寸（如 50×40）
- ✅ 显示预计珠子总数

### 4. 拼豆色系统计
- ✅ 按使用数量排序
- ✅ 显示每种颜色的色号和数量
- ✅ 支持切换品牌重新显示色号

### 5. 导出功能

**导出拼豆图（PNG）**
- 高清图纸（30px 单元格）
- 每个格子标注色号
- 带网格线和边框
- 文件名: `bead-pattern-{宽}x{高}.png`

**导出色系统计（PNG）**
- 颜色列表（色块 + 色号 + 数量）
- 总计数量
- 文件名: `bead-colors-stats.png`

## 🔧 技术实现

### 核心算法

#### 1. 像素化处理
```javascript
// 主导色模式
function getDominantColor(region) {
  统计区域内每种颜色的出现次数
  return 出现最多的颜色
}

// 平均色模式
function getAverageColor(region) {
  累加区域内所有颜色的 RGB 值
  return 平均值
}
```

#### 2. 颜色映射
```javascript
// 使用 color-diff 库的 closest 函数
function findClosestColor(targetRgb, palette) {
  将目标颜色转换为 color-diff 格式
  使用 CIEDE2000 算法计算与色板中每种颜色的差异
  return 差异最小的颜色
}
```

### 依赖库

- **color-diff** (通过 CDN 引入)
  - 版本: 1.4.0
  - 用途: CIEDE2000 颜色差异计算
  - CDN: `https://cdn.jsdelivr.net/npm/color-diff@1.4.0/lib/diff.min.js`

### 数据文件

- **color-palette.json**
  - 色板配置文件，包含 288 种颜色的 HEX 值和多品牌色号映射
  - 应用启动时通过 `fetch` API 异步加载
  - 可独立编辑和扩展，无需修改 HTML 代码

## 🎨 扩展建议

### 添加更多颜色

直接编辑 `color-palette.json` 文件:

```json
{
  "version": "1.0",
  "totalColors": 289,
  "colors": {
    // 现有颜色...

    // 添加新颜色
    "#FFD700": {
      "MARD": "A04",
      "COCO": "E07",
      "漫漫": "B3",
      "盼盼": "3",
      "咪小窝": "3"
    }
  }
}
```

### 添加新品牌

1. 在 `brands` 数组中添加新品牌名称
2. 为每个颜色添加该品牌的色号映射

```json
{
  "brands": ["MARD", "COCO", "漫漫", "盼盼", "咪小窝", "新品牌"],
  "colors": {
    "#FAF4C8": {
      "MARD": "A1",
      "新品牌": "NEW01"
    }
  }
}
```

### 调整预览尺寸

修改 `renderBeadPreview` 函数中的 `cellSize`:

```javascript
// 原代码
const cellSize = Math.min(600 / N, 600 / M);

// 改为更大的预览
const cellSize = Math.min(800 / N, 800 / M);
```

### 修改导出单元格大小

修改导出函数中的 `cellSize`:

```javascript
// 原代码
const cellSize = 30;

// 改为更大的单元格
const cellSize = 40;
```

## ⚠️ 注意事项

1. **浏览器兼容性**
   - 需要支持 ES6+ 的现代浏览器
   - 推荐: Chrome、Firefox、Safari、Edge

2. **图片大小**
   - 建议上传尺寸 < 2000×2000 的图片
   - 过大的图片可能导致处理缓慢

3. **依赖文件**
   - `color-palette.json` 必须与 `index.html` 在同一目录
   - color-diff 库需要网络连接加载 CDN 资源
   - 如需完全离线使用，需下载 color-diff 库到本地并修改引用路径

4. **导出文件**
   - PNG 格式，可直接打印
   - 建议打印前预览尺寸
